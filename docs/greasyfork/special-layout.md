## 功能

将 B 站特殊聚合直播页重排为接近普通直播间的宽屏布局，保留聚合列表，并补齐关注侧栏和回到播放器按钮。

## 使用方法

安装后打开特殊聚合直播页自动生效。若想完全隐藏聚合列表，请改用 no-list 版本；若想直接跳到普通播放器，请改用跳转脚本。
