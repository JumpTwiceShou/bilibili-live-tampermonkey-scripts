## 功能

将 B 站特殊聚合直播页重排为接近普通直播间的宽屏布局，隐藏聚合列表，并补齐关注侧栏和回到播放器按钮。

## 使用方法

安装后打开特殊聚合直播页自动生效。该版本固定隐藏聚合列表；不要与保留列表版本同时启用。
